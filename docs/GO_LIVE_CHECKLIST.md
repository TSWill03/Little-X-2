# Critérios de publicação da Little X 2.0

Este arquivo descreve os **critérios de qualidade da vitrine pública**. O processo detalhado de migração, referências a servidores, cópias de segurança e dependências do código privado são documentados exclusivamente no repositório de desenvolvimento.

## Repositório e pesquisa
- [ ] Conteúdo público revisado quanto a segredos, credenciais, dados pessoais e licenças.
- [ ] O endereço mostrado no banner corresponde ao endereço público acessível sem login.
- [ ] O código privado de desenvolvimento e seus históricos não foram incluídos nesta vitrine.
- [ ] Documentação distingue funcionalidades demonstradas, validadas em versões anteriores e ainda planejadas.
- [ ] Referências acadêmicas e limitações da pesquisa são preservadas.

## Demonstração interativa
- [ ] Há uma URL pública HTTPS funcional para a página MeuX.
- [ ] A demo utiliza banco, sessões, políticas de acesso e configuração independentes dos dados do autor.
- [ ] Cada visitante possui isolamento de conversas e controle de retenção de informações.
- [ ] O modelo realmente utilizado é informado; modos degradados não se apresentam como inferência real.
- [ ] Limites de concorrência, falhas de conexão e indisponibilidade do computador são tratados.
- [ ] Ações externas exigem consentimento e aprovação. Não há acesso a dados acadêmicos ou serviços pessoais sem autorização.
- [ ] O botão **Testar a MeuX** só é disponibilizado quando os itens mínimos acima forem atendidos.
